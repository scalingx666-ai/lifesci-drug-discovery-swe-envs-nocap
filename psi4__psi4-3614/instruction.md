## Description

~This is stacked on #3468 and should merge after it. Until then, the diff against master includes #3468;~ this PR's own
changes are the last three commits, all in `libcinteri.cc` and `libcinteri.h`. They change how much work and memory
the libcint backend spends around the integrals, not the integrals themselves.

### Clones share the optimizers and keep the copied sieve

A clone, one per thread, rebuilt everything its original had:
- the libcint optimizer of each kernel;
- the Schwarz sieve, with all its (MN|MN) integrals;
- the shell-pair blocks.

`TwoBodyAOInt`'s copy constructor already copies the sieve and the blocks, and Libint2's clones keep them. DirectJK
builds an integral object and its clones every SCF iteration, so on n threads the sieve was computed n times per
iteration.

Clones now keep the copied sieve and blocks and size only their own buffers. They share the optimizers, which libcint
only reads while computing, as pyscf shares one across threads. `shared_ptr`s free them with the last user.

### libcint gets its working memory instead of allocating it per call

Unless handed a cache, libcint allocates its working memory and frees it again on every call. Each integral object now
keeps one cache and grows it as needed.

- **Size:** libcint never checks the size of a cache it's handed, so the size comes from libcint itself: a call with a
  null output returns it. The size depends only on the kernel and on each slot's angular momentum and number of
  primitives, so it's asked once per kind of quartet and remembered. Clones start from their original's sizes.
- **Why not a bound computed up front:** for example, from the diagonal quartets of the highest-l and the
  most-primitive shells. That doesn't hold for every kernel in use. erfc doubles the Rys roots only for low total
  angular momentum, and the derivative kernels raise the angular momentum of some slots only.
- **qcint:** asking the library is exact for qcint too. qcint aligns what it takes from the cache to its SIMD width
  and counts on an aligned start, so the cache handed over starts on a 64-byte boundary.

### The mixed-basis transform takes its scratch from `cint_buf_`

For a mix of cartesian and spherical shells, `transform_mixed` used a scratch buffer of its own, as large as the
largest quartet block or sieve block. It now uses the part of `cint_buf_` that held the same component's libcint
output. The repack has just consumed that part, and it holds the full cartesian quartet.
