# Issue

**Title:** num experiments to ask for

## Description

## Motivation
Explained in detail in . 
Expanding functionality available in DoE to Factorial DoE as well. In particular, calculating the number of expected experiments, given the domain.  

Counting must account for:
- fractional/full continuous corners from the active generator
- repetitions and center points (including block replication)
- multiplicative discrete/categorical combinations
This PR adds a strategy-level method so counting is computed once, in the same place as design generation semantics.

## What Changed
- Added `get_required_number_of_experiments()` to `FractionalFactorialStrategy`.
- Implemented exact counting aligned with `_ask()` behavior:
  - continuous count from `fracfact(gen)` and repetitions/centers/blocks
  - discrete/categorical multiplier via `get_number_of_categorical_combinations(include_semicontinuous=False)`
  - exclusion of `block_feature_key` from the categorical multiplier (consistent with strategy behavior)
- Added a changelog entry under `Unreleased`.
- Added tests covering continuous-only, categorical/discrete-only, mixed, and blocked designs.
