# Issue

**Title:** Prefer empty() for rendering container checks

## Description

Part of #3101, limited to `readability-container-size-empty` in `avogadro/rendering/`.

Replace nine container-emptiness conditions across seven files with `empty()` or
`!empty()`. The patch is clang-tidy's generated output, formatted on changed
lines. It preserves the conditions' meaning and leaves size-threshold checks
and the generic `Texture2D::upload` template unchanged. This does not close the
complete multi-directory issue.

### Validation

Ubuntu WSL, GCC 15.2, clang-tidy/clang-format 21.1.8:

- Rendering target builds before and after the patch.
- All 10 rendering CTest groups pass before and after the patch.
- The selected check goes from nine diagnostics to zero across all 42 rendering
  translation units; the final invocation has no compiler errors.
- `git diff --check` passes.

Exact commands, run from the source checkout:

```bash
cmake -S . -B /home/chauhan/avogadro-build-3101 -G Ninja \
  -DCMAKE_BUILD_TYPE=Release -DCMAKE_EXPORT_COMPILE_COMMANDS=ON \
  -DENABLE_TESTING=ON \
  -DUSE_LIBMSYM=OFF -DUSE_SPGLIB=OFF -DUSE_PLOTTER=OFF

cmake --build /home/chauhan/avogadro-build-3101 \
  --target AvogadroRenderingTests --parallel 3
```

`avogadrodata` is cloned alongside `avogadrolibs`. Optional libmsym, spglib and
plotting components are disabled in this configuration. The full project
suite, GUI testing and cross-platform CI have not been run locally; this draft
requests upstream CI and review.

The check was run before and after with:

```bash
run-clang-tidy -p /home/chauhan/avogadro-build-3101 \
  -checks='-*,readability-container-size-empty' \
  -extra-arg=--gcc-install-dir=/usr/lib/gcc/x86_64-linux-gnu/15 \
  -header-filter='avogadro/rendering/' -quiet -j 3 \
  'avogadro/rendering/.*cpp'
```

The final verification used `-j 2`. The GCC-directory option corrects local
clang-tidy standard-library detection. Fixes were generated with the same
