### [`v1.17.1`](https://redirect.github.com/kjanat/actionlint/releases/tag/v1.17.1)

[Compare Source](https://redirect.github.com/kjanat/actionlint/compare/v1.17.0...v1.17.1)

actionlint 1.17.1 updates the Go toolchain and container packages to address the vulnerabilities reported in . It also fixes validation of actions at the repository root. This is a small maintenance release for v1; configuration and check defaults are unchanged.

#### Upgrade to patched binaries and images

The release binaries, Docker images, and Nix package now build with Go 1.27.3, including its standard-library security fixes. Docker images also update their installed Alpine packages.

The release workflow now checks Go packages with govulncheck and scans the Docker smoke-test images with OSV Scanner before publication. Thanks [@&#8203;konard](https://redirect.github.com/konard) for reporting the vulnerable packages in the 1.17.0 image. Related: .

#### Call an action at the repository root

A step using `uses: $/` now resolves to the repository's root action instead of producing an invalid-format error. For a repository with an `action.yml` or `action.yaml` at its root:

```yaml
steps:
  - uses: $/
    with:
      message: hello
```

actionlint reads that action's metadata and validates its inputs and outputs. Unknown input names and references to undeclared outputs still produce diagnostics. Thanks [@&#8203;mattdowdell](https://redirect.github.com/mattdowdell) for reporting the problem and identifying its cause in . Fixed in .
