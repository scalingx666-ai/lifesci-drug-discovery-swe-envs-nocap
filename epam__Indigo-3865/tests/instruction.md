<li>Use the constructed request URL host when validating action request origins. (<a href="">#15185</a>)</li>
<li>Remove the un-documented custom error serialization logic from Data Mode SSR built-in hydration flows (<a href="">#15175</a>)</li>
<li>Validate protocols in RSC render redirects (<a href="">#15177</a>)</li>
<li>Consolidate url normalization logic and better handle mixed slashes (<a href="">#15176</a>)</li>
</ul>
